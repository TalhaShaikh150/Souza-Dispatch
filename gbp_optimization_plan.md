## 2. Biggest Problems We Found
**Problem #1 — Website Is Incomplete**
The website currently has only: Home, Blog, Contact.
There is no dedicated Services page and no individual pages explaining the company's services.
This makes it harder for Google to understand the full range of services SouzaDispatch provides.

**What we should do**
Build a proper website structure:
Home → Services → Local Moving → Office Removals → Furniture Removal → Man & Van → Packing
Services → Waste Removal → etc.
Also create: About, FAQ, Contact, Service-area/location information where appropriate.

## 3. Website Technical SEO Needs Improvement
**Current problems**
- No verified Google Search Console setup
- Sitemap needs to be created/checked
- Schema markup needs to be added/verified
- Some social links don't work
- Contact page URL contains "blank-1"
- Website appears unfinished
- Important service information is missing

**Why this matters**
These aren't all direct GBP ranking factors. However, the website is an important supporting signal because it gives Google more information about:
What the business does, which services it provides, where it operates, which topics it is relevant for.

**Action**
Before focusing heavily on GBP optimization, make the website look complete, trustworthy and technically healthy.

## 4. Create a Strong Services Structure
The GBP allows a large number of services to be added. Currently, SouzaDispatch has only a limited list.
Existing services include:
- In-country moving
- Local moving
- Moving-related packing
- Moving-related waste removal
- Oversized item moving
- Small furniture moving
- Man and Van

**What we should do**
Research competitors ranking for relevant searches such as "removal company London". Look at the services they offer. Then create a master list of potentially relevant services.
Send the list to the client and ask: "Please confirm which of these services SouzaDispatch actually provides." Only add services that the business genuinely offers.

**Important**: Do not copy competitor services blindly.

## 5. Improve GBP Categories
**Current**
Primary category: Removals Company
Secondary categories: None

**Action**
Research competitors and Google's available categories to determine whether SouzaDispatch genuinely qualifies for additional secondary categories. The primary category is especially important because it tells Google what the business mainly is.

## 6. Improve GBP Service Descriptions
Adding services alone isn't enough. Where GBP provides a description field, we can write concise, relevant descriptions for the services. Keep descriptions accurate, natural, relevant, customer-focused, and within Google's character limit.

## 7. Reviews Need Improvement
**Current**
5.0 from 18 reviews (last review was ~6 weeks ago).

**What we should do**
Create a consistent review-generation process. Ask genuine customers to leave honest reviews after completing a job. Ideally, reviews should naturally mention details about the experience (service provided, type of move, area served, quality, professionalism, communication).

**Important**: Never tell customers to write fake reviews or use identical review templates.

## 8. More Photos & Videos
**Current**: 12 photos, 3 videos.
Add authentic photos such as: Vehicles, team members, moving equipment, furniture being handled, packing work, before/after jobs, branded vehicle, team at work, different types of completed jobs.
**Goal**: Make the profile look active, legitimate and trustworthy.

## 9. GBP Posts
**Current**: ~3 GBP posts.
We can create posts about: Services, completed jobs, moving tips, packing tips, seasonal moving advice, areas served, FAQs, promotions, new photos/projects. Provide useful information rather than simply stuffing keywords.

## 10. Create an FAQ Section
The website currently has no FAQ page. We can create an FAQ section answering real customer questions (e.g., costs, packing services, large furniture, man and van, waste removal, advance booking, office moves, areas covered).

## 11. Improve Website Titles & Headings
Each important service page should have a clear title and H1.
For example:
Title: Removal Company in London | SouzaDispatch
H1: Removal Company in London
The page content should then clearly explain what the service is, what is provided, areas served, how to book, and FAQs.

## 12. Build Location Relevance Naturally
Because SouzaDispatch is a service-area business, we need to clearly communicate where it operates. The website should naturally mention the actual areas SouzaDispatch serves (London, specific boroughs). Only create useful location pages when there is enough unique information to make them genuinely valuable.

## 13. LocalBusiness / Organization Schema
Implement relevant schema such as LocalBusiness, Organization, Service, WebSite, FAQPage where eligible to help search engines understand the website's information in a structured way.

## 14. Google Search Console
**Current**: Not connected/submitted.
**Action**: Set up Google Search Console for the website. Verify the website, submit the sitemap, check indexing, monitor search queries, identify technical issues.

## 15. Competitor Research
Before making major changes, we should study businesses already ranking for terms like: Removal company London, Removals London, Man and van London, House removals London, Furniture removal London.
Record their: Primary/Secondary categories, reviews, photos, services, website pages, service pages, location targeting, website quality, content, GBP activity.

## 16. What Is Probably Holding SouzaDispatch Back?
**High Priority**
1. Weak/incomplete website
2. Limited GBP optimization
3. Low review volume
4. Limited profile activity/content
5. Need stronger local relevance

**Medium Priority**
Search Console setup, Sitemap, Schema, FAQ content, Better page titles/H1s, More website service pages, Fix broken social links, Fix Contact page URL, Improve website trust signals.

**Ongoing**
Genuine customer reviews, New photos, GBP posts, Competitor monitoring, Ranking tracking, Website content improvements.

## 17. Important: Why Isn't the GBP Ranking?
Google's Local Pack ranking is influenced primarily by Relevance, Distance, and Prominence. Fixing the website alone will not guarantee a Top 3 ranking. Our job is to improve the overall signals while measuring the ranking changes.

## 18. Our Optimization Process
**Phase 1 — Baseline**: Track current rankings, competitors, GBP information, website condition.
**Phase 2 — Website**: Fix broken pages/links, improve structure, create Services pages, improve titles/H1s, add useful content, create sitemap, connect Search Console, implement schema.
**Phase 3 — GBP**: Review primary category, research secondary categories, expand services, add descriptions, improve business info, add photos/videos, create posts.
**Phase 4 — Reviews & Authority**: Build genuine review process, continue adding photos, build local citations, improve website authority.
**Phase 5 — Track Results**: Monitor rankings, queries, impressions, calls, clicks, reviews.

## Final Assessment
SouzaDispatch has a strong starting point (5.0 rating, 18 reviews, correct primary category, website, some photos/posts/services). But there is significant room for improvement. The biggest immediate opportunity is to finish and strengthen the website, improve GBP setup, increase reviews, add visual content, and establish an optimization process.
Make changes systematically and measure improvements.
